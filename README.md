# دعوة زفاف سيف ونور 🤍

موقع دعوة زفاف — HTML/CSS/JS بس، من غير build ولا مكتبات، يشتغل على GitHub Pages على طول.

**التفاصيل:** الجمعة ٢ أكتوبر ٢٠٢٦ — الساعة ٨ مساءً — قاعة Grand VIP، سوهاج.

## اللي في الموقع

- **شاشة افتتاح على شكل ظرف** بختم شمع (س ♡ ن)، وورد أبيض بيتمايل في الأركان — الضغط على الختم بيفتح الظرف ويشغّل الأغنية
- **غلاف بالصورة ملء الشاشة** والأسماء بخط نستعليق (على الكمبيوتر الصورة بتبقى على نص الشاشة)
- بتلات ورد بتنزل خفيف، والآية، ونص الدعوة
- **كارت التاريخ** بشكل قوس: الجمعة | ٢ أكتوبر ٢٠٢٦ | ٨ مساءً
- **عد تنازلي بحلقات** بتفضى مع الوقت
- كارت المكان بخريطة جوجل مدمجة + الاتجاهات + أضف للتقويم + مشاركة
- **دعوة باسم الضيف** — `?to=الاسم`

## الموسيقى

`audio/song.webm` (كروم/فايرفوكس) و`audio/song.m4a` (آيفون/سفاري) — متاخدة من فيديو الواتساب،
٤٠ ثانية وبتلف. زرار عائم تحت الشمال للتشغيل/الإيقاف، واختيار الزائر بيتحفظ.
المتصفحات بتمنع الصوت قبل أول ضغطة، عشان كده الأغنية بتبدأ مع فتح الظرف.

لتبديل الأغنية:

```bash
ffmpeg -i جديدة.mp4 -vn -c:a libopus -b:a 96k  audio/song.webm
ffmpeg -i جديدة.mp4 -vn -c:a aac     -b:a 128k audio/song.m4a
```

## تعديلات سريعة

- **الأسماء / التاريخ / المكان:** نص عادي في `index.html`.
- **موعد العد التنازلي والتقويم:** أول سطور `script.js` (الشهر بيبدأ من صفر، `9` = أكتوبر) و`event.ics`.
- **الألوان:** `:root` في أول `styles.css`.
- **الصورة:** `images/couple.jpg` (طولية ٢:٣).

## الورد

باقة الورد في شاشة الافتتاح متولّدة بسكربت (ورد أبيض + ورق أخضر + ورد الجبس، زي الصورة):

```bash
python3 tools/gen_flowers.py > tools/bouquet.svg
```

وبعدها بدّل اللي جوّه `<symbol id="bouquet">` في `index.html` بمحتوى الملف.
